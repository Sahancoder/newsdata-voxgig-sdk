## 4. Testing Before Release

Before creating a release:

1. Install dependencies.
2. Build SDK.
3. Run unit tests.
4. Run relevant component tests.
5. Run controlled integration test.
6. Run security checks.
7. Review documentation.

---

## 5. Versioning

Semantic versioning may be used:

```
MAJOR.MINOR.PATCH
```

Example:

```
0.1.0
```

Do not create unnecessary release versions for the assessment.

## 7. GitHub
